# Прототип интеллектуальной системы адаптаций кулинарных рецептов RecipeManager

Интеллектуальная система адаптации кулинарных рецептов с использованием методов искусственного интеллекта. 
Позволяет автоматически модифицировать рецепты под наличие продуктов пользователя, аллергии и диетические ограничения.


## Возможности
🍳 Адаптация рецептов под наличие продуктов (недостаток/избыток)

🔄 Интеллектуальная замена ингредиентов с оценкой уверенности

🚫 Учет пищевых аллергий (лактоза, глютен, яйца и др.)

🥗 Поддержка диет (Кето, Веган, Вегетарианец, Без сахара)

📏 Автоматическое масштабирование рецепта

👥 Расчет количества порций

📝 Добавление собственных рецептов

🔍 Поиск по базе рецептов

## Требования
- Python 3.8+
- Установленные зависимости из requirements.txt

## Установка
1. Клонировать репозиторий:
```bash
git clone https://github.com/yarkoann/RecipeManager
cd RecipeManager
```
2. Создать виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # для Linux/Mac
venv\Scripts\activate     # для Windows
```
3. Установить зависимости:
```bash
pip install -r requirements.txt
```
4. Запуск
```bash
streamlit run app.py
```
