# Прототип интеллектуальной системы адаптаций кулинарных рецептов RecipeManager

Интеллектуальная система адаптации кулинарных рецептов с использованием методов ИИ.  
Автоматически модифицирует рецепты под наличие продуктов, аллергии и диетические ограничения.

---
## Возможности
- **Адаптация рецептов** под наличие продуктов у пользователя
- **Интеллектуальная замена ингредиентов** с оценкой уверенности ИИ
- **Учёт аллергий** (лактоза, глютен, яйца, орехи и др.)
- **Поддержка диет** (Кето, Веган, Вегетарианец, Без сахара)
- **Масштабирование рецепта** под количество продуктов

- **Расчёт количества порций** по весу ингредиентов

- **Добавление, редактирование, дублирование** собственных рецептов

- **Поиск рецептов** по названию, категории и имеющимся продуктам

- **Расчёт КБЖУ** (калории, белки, жиры, углеводы) на блюдо и порцию
- **Экспорт** адаптированного рецепта в текст

## Требования
- Python 3.8+
- Установленные зависимости из requirements.txt

## Установка и запуск
1. Клонировать репозиторий:
```bash
git clone https://github.com/yarkoann/RecipeManager
cd RecipeManager
```
2. Создать виртуальное окружение:
```bash
python -m venv .venv
source .venv/bin/activate  # для Linux/Mac
.venv\Scripts\activate     # для Windows
```
3. Установить зависимости:
```bash
pip install -r requirements.txt
```
4. Запуск
```bash
streamlit run app.py
```
5. Формат ввода продуктов
```
мука 500г, яйца 3 шт, молоко 200мл, горох 1 банка
```

- Оставив поле пустым — считается, что все ингредиенты есть
- Указать `0` для отсутствующего продукта: `яйца 0 шт`
- Поддерживаются банки: `горох 1 банка` (автоматически переводятся в граммы)
